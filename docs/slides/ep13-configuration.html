Why images stay portable.

  • Images stay portable. Environments differ by config, not rebuilds.
  • Secrets stay out of Git history. A pushed password persists after deletion.
  • Scope limits damage. Read access to a Secret reads the password.

06:00 · LimitsWatch out

Limits and tradeoffs

Decodable secrets. Restart gap.

  • Base64 decodes openly. Anyone with the file reads the value.
  • Unencrypted by default. Real clusters add encryption at rest and access rules.
  • Config changes need restarts. Running Pods do not re-read automatically.
  • Wrong namespace breaks pods. The Secret must live with the workload.
Tradeoff. Command-line Secrets stay simple but sit outside GitOps. Sealed Secrets later close that gap.

Speaker cue: Name the failure mode before the fix. The doc holds the fix steps.
