06:00 · Act 2Cloud Engineer · Stone

Act 2 · 06:00

Act 2: You are a Cloud Engineer.

Plan the machine, then build the same machine twice: local first, cloud second.

  • Plan it: CPU, memory, storage, firewall, CIDR, DNS, cost
  • Provision it: cloud-init on Multipass, then Terraform on GCP
  • Configure it: idempotent Ansible playbook (safe to run twice)
  • Prove it: app answers, port 8000 stays closed, terraform destroy at the end
Multipasscloud-initAnsibleTerraformGCP

Speaker cue: Stress idempotence and cost safety: budget alert first, destroy last. Ep 10 is optional hands-on without a trial.

09:00 · Act 4Security · River Blue

Act 4 · 09:00

Act 4: Attack, then defend.

You are a Cybersecurity Engineer. Think like an attacker first.

  • Attack: map the API, find SQL injection in /api/tasks/search, exploit by hand and with sqlmap
  • Fix: parameterized query, default-deny NetworkPolicies
  • Verify: Semgrep (code), Trivy (images, IaC, secrets), ZAP (live headers)
  • Second bug: broken access control (JWT, ownership check) and Sealed Secrets for GitOps
Penetration testingsqlmapNetworkPoliciesTrivy + ZAP

Speaker cue: Sequence matters: exploit first (20 to 21), fix and scan second (22 to 23), then access control and secrets (24 to 25).
